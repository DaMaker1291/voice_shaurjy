# Second Brain Desktop App

## Development

```bash
# From the desktop/ folder
npm start
```

## Build Installer

```bash
# Build Windows installer (.exe)
npm run dist

# Output: desktop/dist/SecondBrain-Setup-1.0.0.exe
```

## Requirements

- Node.js 18+
- Python 3.11+ with `.venv/` at project root
- All Python dependencies installed
